# Pizza Hut Overview

## Pizza Hut Cyprus

Pizza hut in Cyprus operates over 30 stores, some are more delivery oriented and some are more Dine In focused.

- Pizza hut sales in the majority are pizzas.
- Pizzas have different sizes,you can filter by size on 'transaction_details' table by filtering the column 'trde_size' on the following terms
- Pizzas have also different dough types as a base for the pizza. Those can be filtered on 'transaction_details' table by filtering the column 'trde_type'
