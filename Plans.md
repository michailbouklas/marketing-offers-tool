## Decisions logged

From `/harness-plan` clarifiers, 2026-05-26:

- **Persistence**: DB metadata + local file storage. `UPLOADS_DIR` env-required.
- **Access**: All authenticated users (no new role).
- **Edit**: Menu with two options — Re-prompt **and** Edit with reference image (image-to-image preserved from prototype).
- **All Models fan-out**: 3 per model (configurable, default 3, bounded by `SAMPLES_PER_MODEL_MAX=5`). Raises the prototype's 1-per-model.
- **Brand pipeline**: dropped from v1. Brand kits, logo overlay, headline overlay, custom font upload, and `buildPrompt` brand rules are deferred to a later phase. Removed from the spec's UI and persistence.
- **Prompt enhancement**: kept from prototype (`POST /api/images/enhance`, OpenAI chat completions with clarifying-Q flow).
- **Reference images**: kept from prototype, refactored to a dedicated upload endpoint with persisted IDs (`ReferenceImage` model) so generation requests reference them by id, not by inline multipart.
- **Env naming**: keep prototype's `IMAGE_ROUTER_*` naming (not `IMAGEROUTER_*`). Add `OPENAI_IMAGE_MODELS`, `UPLOADS_DIR`, `SAMPLES_PER_MODEL_MAX` as new vars.
- **Timer format**: seconds with one decimal place (matches prototype). Not `mm:ss`.
- **Provider files**: live in `src/lib/services/image-providers/*.server.ts` (SvelteKit convention), porting from prototype's `src/providers/*.ts`.
